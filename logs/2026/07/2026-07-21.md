# Captain's Log — 2026-07-21
Maintenance day. The kind of day that doesn't produce exciting demos but absolutely matters — both projects got meaningful hardening work across the board.

The bulk of the day went into private-project-2, which is a React-based frontend that had accumulated a solid backlog of technical debt and polish items. I worked through a first round of maintenance tasks more or less systematically. The most important thing I shipped was removing sensitive console logging across ten files — data that should never have been reaching browser devtools in production. That one should have been caught earlier, and I'm glad it's gone now.

Dependency hygiene followed: semver-safe updates across the board, npm audit resolved. These are easy to defer indefinitely, so I've made a point of treating them as first-class backlog items rather than "eventually." On a related note, I fixed a runtime crash in the signup schema caused by a breaking behavior in Zod 4.4 — the kind of subtle incompatibility that surfaces only after a dep bump and bites you in production if you're not paying attention.

The accessibility and SEO work was more involved than I expected. Making icon controls keyboard-operable touched four files and required thinking carefully about focus management and ARIA semantics — it's not just slapping `tabIndex={0}` on a div. The SEO pass was the largest single change of the day: robots.txt plus per-route metadata across fifteen files, which means the app now actually tells crawlers something coherent about itself.

I also fixed a genuinely annoying React hydration issue that was blocking the cookie management link in the footer — a case where React's event handling was intercepting a navigation that needed to escape the component tree. Ended up needing a targeted workaround rather than a clean solution, but it works. Cleaned up eight placeholder files from the public directory and removed legacy code artifacts while I was at it.

Over in private-project-1, a resilience fix for the download processing pipeline landed via PR merge. Three files changed — likely retry logic or error boundary work, which fits the theme of the day: making things fail gracefully instead of loudly.
