# Captain's Log — 2026-07-30
Cinema work dominated the day across two separate projects — content gating on the backend and UI polish on the frontend.

The more consequential change was in private-project-1: tightening the publication gate so that only records explicitly marked "Publié" make it to the live environment. Previously the logic was opt-out, or at least permissive enough that records could slip through before they were editorially ready. Flipping this to opt-in is the right call — it puts the default in a safe state, which is almost always the correct posture for a CMS-adjacent publication pipeline. Three files touched, which suggests it was a targeted, surgical change rather than a broader refactor. Those are satisfying to ship.

Over in private-project-2, the cinema feature branch is taking shape. The merge from the search bar branch consolidated a meaningful chunk of work — five files — into the main cinema feature line. Search integration on a cinema context usually means thinking carefully about filtering (genre, date, language, venue) and how those map to whatever index or query layer is underneath. Good to have that merged and stabilized into the feature branch rather than letting it drift in isolation.

The cosmetic fix to align the homepage cinema promo with the cinema section header is the kind of thing that's easy to dismiss but actually matters. Visual inconsistency between a promo unit and the section it's promoting breaks the implicit contract with the user — they should feel like they're looking at the same thing. Two files, probably some shared styles or layout tokens brought into sync.

Overall a focused day. The cinema feature is converging, which means integration testing and edge-case hunting are probably next on the agenda.
