# Captain's Log — 2026-07-29
Heavy day. Three projects in motion simultaneously, which always sounds more glamorous than it feels mid-afternoon.

The bulk of the work landed on a cinema-focused frontend project where a "Ciné Panache" collection feature has been taking shape. A lot of today was about getting the details right: a dedicated collection header, film credits that reflow gracefully across breakpoints, and a favoriting system so users can save collections alongside individual films. The kind of feature work that's 20% architecture and 80% edge cases — what do you show on the collection page when the card already *is* on that collection page? You hide the redundant collection name. What about the eyebrow link that points back to the collection? It needs an underline, but only on hover, and it has to be styled as a bottom border so it doesn't push layout. None of these decisions are hard in isolation, but they compound quickly when you're working across five files at a time.

The carve-out for Panache specifically — not overlaying collection titles on its vignettes, using a smaller file-text icon on pedagogical document cards, shortening and recoloring the cinema advisory tooltip — reflects a pattern I've been navigating all week: this collection has its own visual identity that doesn't fully inherit the generic collection treatment. Threading that needle without forking the entire component tree takes discipline.

Over in a second private project, I shipped a tag-filter system for a vertical content feed. The v1 is deliberately frontend-only — story-category pills that narrow what's visible without touching the server. It's the right call for a first iteration: fast to ship, easy to validate with real users, and the persistence-across-reloads behavior (using local state serialized to the URL or storage, based on the client ask) means it doesn't feel throwaway even before backend filtering exists. Randomized feed order went in alongside it, which pairs naturally — you want the ordering to feel fresh if users are returning repeatedly.

Finally, a small but meaningful change in a third project: Partenaire collections now take priority as a film's primary collection. That kind of data-model decision tends to surface late, once real content starts flowing through and editorial priorities become clear. Good to get it locked down now.
