# Captain's Log — 2026-08-05
The age-restriction enforcement work consumed most of the day — and it was overdue. During the Paperbits migration we apparently lost a whole chunk of logic that gates rated content behind user profile verification. The original implementation was scattered across a few middleware points and a couple of React components, and the migration just… didn’t carry it over. Classic.

I started by restoring the core enforcement logic in the content-page gatekeeper, but I also took the opportunity to tighten the design. Instead of a simple “block if not verified” approach, I reworked it to fail closed on any page that requires age verification when the profile can’t be resolved. Profile resolution failure shouldn’t be a soft 404 — it should be a hard denial. That’s the only safe default when compliance is at stake.

The trickier part was the Algolia integration. We federate search results from Algolia, and those results are supposed to respect age filters derived from the user’s verified profile. But the query was firing before the profile was resolved, so we’d briefly show unfiltered results. I introduced a deferred query pattern: hold the Algolia search request until the age filters are fully resolved, then fire it. This required threading a promise through the data layer and the search component. The result is a slightly more complex loading state, but it’s correct — no more flash of unrated content.

I also addressed the login edge case: when a user logs in, the gatekeeper on their current page should close immediately if they’re now verified. Previously, it only re-evaluated on navigation, which meant a stale denial state until the next route change. One-line fix in the auth handler, but it closes a real UX gap.

The commits went through a few iterations — the duplicate messages reflect some rebasing and squashing after code review. The PR itself was straightforward to merge once the review comments were addressed. Overall, this feels like a solid piece of compliance work. The Paperbits migration debt is slowly getting paid down.
