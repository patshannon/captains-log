# Captain's Log — 2026-08-25

This is the tool writers will use to document their game playthroughs, stitching together narrative beats, screenshots, and annotations into something that can feed into the larger editorial pipeline. The architecture is deliberately lightweight: a React frontend with a local-first data layer using IndexedDB, so writers can work offline and sync when they're ready. I chose that over a full API-dependent model because latency and connectivity shouldn't interrupt the creative flow.
