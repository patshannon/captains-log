# Captain's Log — 2026-05-13
Spent most of today untangling the change-email flow in a private project to properly align it with the paperbits source of truth. Seventeen files touched, which tells you something about how far the drift had gone — what should have been a localized concern had tentacles in a lot of places.

The core issue with these kinds of alignment efforts is that paperbits has well-defined opinions about how content and component state should be managed, and when you work around those conventions instead of with them, the workarounds compound over time. Getting back in sync meant tracing each deviation back to its origin and deciding whether to pull the code toward the framework or find a cleaner seam where the two could coexist. Mostly it was the former.

Email flows specifically tend to accumulate this kind of debt because they touch auth, user profile state, and UI feedback all at once — lots of opportunity for different parts of the codebase to each have their own partial understanding of "current email." Consolidating around a single source of truth simplifies the mental model considerably, even if the refactor itself is tedious.

Not a glamorous day, but the kind of work that pays forward. Codebases get easier to reason about when the conventions are actually followed.
